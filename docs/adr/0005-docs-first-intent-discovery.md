# Discover project intent from evidence before questioning the user

Repo-curator first reconstructs project intent and the scientific mainline from scoped project rules, README material, research documents, workflow declarations, releases, freezes, and sanitized Git history. Consistent evidence proceeds without user confirmation. Only a conflict or gap that would materially change preservation, recommendation, or safe action produces one evidence-specific question with its evidence, consequences, and conservative recommendation. Users may skip or be unable to answer; the affected conclusion then remains `UNRESOLVED`, relevant material stays protected, and unrelated analysis continues. This preserves the useful reasoning pattern of a rigorous document-grounded interview without turning repository curation into a mandatory questionnaire.
