# Separate repository curation from experiment reproduction

Repo-curator stops at retrospective evidence reconstruction and approved reversible repository organization. It may inspect already-present workflow declarations and run records, but it does not execute project code, notebooks, workflows, containers, package managers, or experiments. It reports reproducibility-evidence completeness without claiming scientific validity or successful reproduction. Executable reproduction handoffs and orchestration are outside the current supported scope; standards exports describe curation observations and hypotheses only. This keeps the Skill focused on the post-chaos curation problem and avoids expanding its dependency, security, and validation surface into that of a reproduction platform.
