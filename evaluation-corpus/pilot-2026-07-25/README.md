# Public Source Registry

This directory retains public computational-research source identities for
descriptive regression planning. It is not needed to install or run the
repo-curator Skill and does not establish `ADMISSION_READY`.

## Retained Material

- `snapshot-registry.json` and `artifacts/repository-snapshots/` identify ten
  public frozen repository sources by URL, commit, root tree, and descriptor hash.
  They are source records, not checkouts or claims that external data remains
  available.
- `tests/fixtures/representative-audit-slices.json` retains three
  content-minimized, offline regression oracles: one bioinformatics workflow,
  one neuroimaging pipeline, and one climate-modeling repository. Each keeps a
  deterministic positive observation together with its conservative
  limitation and non-executable review outcome.

Complete audit runs, reviewer records, human labels, rendered reports, and
private-repository-derived evidence are intentionally excluded from the public
source tree. Public source identities may be used to regenerate read-only
observations if a formal evaluation program is explicitly resumed.

All acquisition and auditing remains read-only. Never execute target code,
install target dependencies, or fetch project data merely to validate this
registry.
